# نصب نسخه تستی روی لیارا

این راهنما برنامه را روی [لیارا](https://liara.ir) (سرویس ابری ایرانی) بالا می‌آورد تا بدون دسترسی به سرور اصلی بتوانید آن را تست کنید.
چرا لیارا: از داخل ایران بدون فیلترشکن کار می‌کند، پرداخت ریالی دارد و «دیسک» دائمی می‌دهد تا دیتابیس و عکس‌ها با هر استقرار پاک نشوند.

فایل `liara.json` در ریشه پروژه همه تنظیمات فنی (Dockerfile، پورت ۳۰۰۰، دو دیسک) را دارد.

## ۱. ثبت‌نام و ساخت برنامه (فقط یک بار)

1. در https://console.liara.ir با شماره موبایل ثبت‌نام کنید و حساب را کمی شارژ کنید (هزینه ساعتی حساب می‌شود؛ کوچک‌ترین پلن برای تست کافی است).
2. «برنامه‌ها» ← «ایجاد برنامه» ← پلتفرم **Docker** ← نام برنامه را `roya-card-test` بگذارید (اگر این نام گرفته شده بود، نام دیگری بگذارید و همان را در `liara.json` جلوی `"app"` بنویسید).
3. داخل برنامه ← «دیسک‌ها» ← دو دیسک بسازید (هر کدام ۱ گیگ کافی است):
   - نام `data`
   - نام `uploads`
4. داخل برنامه ← «تنظیمات» ← «متغیرهای محیطی»، این سه را اضافه کنید:

   | نام | مقدار |
   |---|---|
   | `ADMIN_PASSWORD` | یک رمز دلخواه، حداقل ۱۰ کاراکتر |
   | `SESSION_SECRET` | یک متن تصادفی بلند (حداقل ۱۶ کاراکتر) |
   | `PUBLIC_ORIGIN` | `https://roya-card-test.liara.run` (آدرس برنامه شما) |

## ۲. استقرار (هر بار که کد عوض شد)

روی کامپیوتر خودتان (Node.js نسخه ۲۲ نصب باشد):

```bash
git clone https://github.com/jafarmrt/ecard.git
cd ecard
npm install -g @liara/cli
liara login
liara deploy
```

ساخت ایمیج چند دقیقه طول می‌کشد. پس از پایان، برنامه روی `https://roya-card-test.liara.run` بالاست.

> اگر در کنسول لیارا گزینه اتصال به گیت‌هاب را دیدید، می‌توانید به‌جای خط فرمان، مخزن `jafarmrt/ecard` شاخه `main` را وصل کنید تا هر تغییر خودکار مستقر شود. همان `liara.json` استفاده می‌شود.

## ۳. تست

- سلامت سرور: `https://roya-card-test.liara.run/api/health` باید `{"status":"ok"}` برگرداند.
- پنل مدیریت: `https://roya-card-test.liara.run/admin` با رمز `ADMIN_PASSWORD`.
- یک کارت بسازید، عکس بگذارید و صفحه کارت (`/نامک-کارت`) را با موبایل باز کنید.
- برنامه را از کنسول یک بار «ری‌استارت» کنید و ببینید کارت و عکس هنوز هستند (یعنی دیسک‌ها درست وصل شده‌اند).

## نکته‌ها

- این نسخه تستی است: داده واقعی کارمندان را فقط اگر لازم است وارد کنید.
- برای انتقال داده نسخه قدیمی: از پنل مدیریت سرور قدیم «پشتیبان» بگیرید و در پنل نسخه تستی «بازیابی» کنید.
- پس از پایان تست، برای جلوگیری از هزینه، برنامه را از کنسول خاموش یا حذف کنید.
- همین Dockerfile با `docker compose -f deploy/docker-compose.yml up -d` روی هر سرور لینوکسی هم اجرا می‌شود.
