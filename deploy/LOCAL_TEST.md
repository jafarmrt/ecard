# تست برنامه روی کامپیوتر شخصی

دو راه هست. اگر می‌خواهید دقیقاً همان چیزی را تست کنید که روی سرور اوبونتو نصب می‌شود، راه ۱ را بروید.

## راه ۱: اوبونتو داخل ویندوز (WSL) — همان نصب سرور

۱. PowerShell را **Run as administrator** باز کنید و بزنید:

```powershell
wsl --install -d Ubuntu-24.04
```

کامپیوتر را ری‌استارت کنید. بعد از ری‌استارت پنجره اوبونتو باز می‌شود و یک نام کاربری و رمز می‌خواهد.

۲. در پنجره اوبونتو:

```bash
git clone https://github.com/jafarmrt/ecard.git
sudo bash ecard/deploy/install.sh
```

۳. در مرورگر ویندوز `http://localhost:3000` و پنل `http://localhost:3000/admin` را باز کنید. رمز پنل در پایان نصب چاپ شده است.

به‌روزرسانی هم دقیقاً مثل سرور است: `sudo roya-card update`

نکته‌ها:
- اگر نصب پیام «systemd فعال نیست» داد، در اوبونتو بزنید `echo -e "[boot]\nsystemd=true" | sudo tee /etc/wsl.conf`، سپس در PowerShell `wsl --shutdown` و دوباره اوبونتو را باز کنید.
- برای باز کردن کارت با **گوشی** روی همان وای‌فای، WSL باید در حالت شبکه mirrored باشد: در ویندوز فایل `%UserProfile%\.wslconfig` را با این محتوا بسازید و `wsl --shutdown` بزنید:
  ```ini
  [wsl2]
  networkingMode=mirrored
  ```
  سپس در گوشی `http://IP-کامپیوتر:3000` را باز کنید (IP را با `ipconfig` ببینید؛ اگر باز نشد، پورت ۳۰۰۰ را در فایروال ویندوز باز کنید).
- به‌جای WSL می‌توانید یک ماشین مجازی اوبونتو (VirtualBox با شبکه Bridged) بسازید و همین دو خط را بزنید. این حالت دقیقاً شبیه سرور داخلی است و گوشی هم مستقیم به آن وصل می‌شود.

## راه ۲: اجرای سریع روی ویندوز (بدون لینوکس)

۱. Node.js نسخه 22 (LTS) را از https://nodejs.org نصب کنید.
۲. کد را دانلود کنید: در گیت‌هاب، دکمه سبز **Code** ← **Download ZIP**، و فایل را از حالت فشرده خارج کنید.
۳. روی فایل `start-windows.bat` دوبار کلیک کنید.

بار اول بسته‌ها نصب می‌شوند (چند دقیقه). سپس آدرس و رمز پنل در همان پنجره نوشته می‌شود و برنامه روی `http://localhost:3000` اجرا می‌شود. برای خاموش کردن، پنجره را ببندید.
داده‌ها در پوشه `data` و عکس‌ها در `public\uploads` همان پوشه می‌مانند.

روی مک یا لینوکس هم با Node.js 22 همین کار را این‌طور انجام دهید: `npm ci && npm run local`
